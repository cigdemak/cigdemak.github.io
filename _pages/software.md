## Software

- **[scMKL](https://github.com/ohsu-cedar-comp-hub/scMKL/)** (with [documentation](https://ohsu-cedar-comp-hub.github.io/scMKL/scmkl.html))  <br>
  Python package for scalable multiple kernel learning using Random Fourier Features and Group Lasso. Enables scalable interpretable classification in single-cell multiomics.

- **[EpiConfig](https://github.com/ohsu-cedar-comp-hub/Epiconfig_pipeline)**  <br>
  Snakemake pipeline for running the EpiConfig R package, which implements an LDA model for single-cell multiomics. Epiconfig, is an interpretable multimodal topic model that learns unsupervised clustering of single-cells while modeling cross modality relationships.

- **[EpiConfig Interpretation Tool](https://cigdemak.shinyapps.io/EpiConfig_TEAseq_PBMCs/)** <br> 
  I developed a shiny app for interpretation of multimodal EpiConfig topics to obtain biological insights into different cell states; we show that cross modality features reflect 3D genome interactions.

- **[UrbanOccupationsOETR](https://github.com/cigdemak/UrbanOccupationsOETR)** (with [Live app](http://midas.ku.edu.tr/UrbanOccupationsOETR/)) <br> 
  Shiny app for the *Industrialisation and Urban Growth from the mid-nineteenth century Ottoman Empire to Contemporary Turkey in a Comparative Perspective, 1850-2000* to help investigate the link between ethnicity and profession using spatiotemporal data.

- **[sgp_covid-19](https://github.com/cigdemak/sgp_covid-19)** (with [Live App](https://cigdemak.shinyapps.io/sgp_covid-19/))  <br>
  R implementation of structured Gaussian processes with multiple kernel learning for the analysis of COVID-19 pandemic dynamics in the United States in [Ak et al 2022](https://doi.org/10.3390/ijgi11090470).
    
- **[Prospective CCHF](http://midas.ku.edu.tr/ProspectiveCCHF)** <br>
  A platform for spatiotemporal analysis of Crimean-Congo Hemorrhagic Fever (CCHF). It provides access to input covariates, nationwide surveillance data, and prediction results for 2004-2017, as well as maps and model performance metrics in [Ak et al 2020](https://doi.org/10.1016/j.cmi.2019.05.006).

- **[sgp2mkl](https://github.com/cigdemak/sgp2mkl)**  <br>
  R implementation of structured Gaussian processes with multiple kernel learning in [Ak et al. 2018](https://proceedings.mlr.press/v95/ak18a/ak18a.pdf).

## Code

- **[Power analysis for spatial analysis](https://github.com/cigdemak/cycIF_prostate)**  
  Code and documentation for spatial variability and sample size effects in prostate cancer progression. Includes statistical analyses: in silico tissue generation, leave-one-out analysis, subsampling, and permutation tests in [Ak et al. (2024)](https://www.cell.com/iscience/fulltext/S2589-0042(24)01893-5).
